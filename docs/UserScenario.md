# 마이링크 (MyLink) 사용자 시나리오 (User Scenario)

## 1. 방문자 (Visitor) 시나리오

### 1-1. 페이지 접속 및 탐색
* 사용자는 **특정 크리에이터의 소셜 정보 및 포트폴리오를 한곳에서 확인하기 위해** 외부에 공유된 고유 프로필 주소(`mylink.com/디스플레이네임`)를 **클릭한다**.
* 사용자는 **크리에이터가 제공하는 구체적인 목적지(웹사이트, 영상 등) 목록을 알아보기 위해** 브라우저에 렌더링된 반응형 퍼블릭 페이지를 상하로 **탐색한다**.

### 1-2. 개별 링크 클릭 및 통계 집계 트리거
* 사용자는 **크리에이터가 연동해 둔 외부 특정 콘텐츠로 직접 이동하기 위해** 파비콘이 포함된 링크 버튼 중 하나를 찾아서 **클릭한다**.
* 사용자는 **마이링크 프로필 화면을 유지한 채로 목적지 콘텐츠를 편하게 소비하기 위해** 브라우저 '새 탭(새 창)'에 콘텐츠가 열리는 것을 **기다린다**.
* *(보이지 않는 시스템 동작: 사용자가 링크를 클릭하는 순간, 시스템은 해당 링크의 고유 ID를 추적하여 '해당 링크의 개별 클릭 조회수(Click Count)'를 +1 증가시킨다.)*

## 2. 채널 소유자 (Owner) 시나리오

### 2-1. 가입 및 로그인 (온보딩)
* 사용자는 **복잡한 아이디/비밀번호 생성 과정 없이 서비스를 바로 시작하기 위해** 메인 화면의 '구글 계정으로 시작하기' 버튼을 **클릭한다**.
* 사용자는 **자신만의 고유한 마이링크 주소를 확보하기 위해** 본인이 가입한 구글 Gmail 아이디 앞부분(Prefix)이 본인의 `displayName`이자 URL 슬러그로 자동 맵핑되어 열린 대시보드 화면을 **확인한다**.

### 2-2. 프로필 정보 관리 (인라인 수정)
* 사용자는 **방문자에게 보여지는 본인의 활동명(닉네임/슬러그)을 원하는 이름으로 변경하기 위해** `displayName` 영역의 연필 아이콘을 누른 후 내용을 수정하고 키보드 엔터키(Enter)를 **쳐서 저장한다**.
* 사용자는 **변경된 `displayName`에 따라 본인의 퍼블릭 접속 URL(`mylink.com/새닉네임`)이 최신화되었는지 확인하기 위해** 대시보드의 내 URL 표시 영역을 **확인한다**.
* 사용자는 **활동명과 별개로 자신의 실제 본명이 보이게 하기 위해** `username`(실제 이름) 영역을 클릭 후(인라인 편집) 새로운 이름으로 **수정한다**.
* 사용자는 **본인의 프로필에 접속한 방문자들에게 짧은 인사말이나 채널 특징을 안내하기 위해** 소개글(Bio) 영역을 클릭하여 인라인 편집으로 내용을 **작성한다**.

### 2-3. 링크 CRUD 관리 (추가/수정/삭제)
* 사용자는 **본인의 새로운 웹사이트나 영상을 프로필 리스트에 담기 위해** 대시보드의 '새 링크 추가' 입력란에 대상 URL과 제목을 기입하고 '추가' 버튼을 **클릭한다**.
* 사용자는 **새로 추가한 링크가 올바르게 작동하고 대상 사이트의 파비콘(Favicon) 이미지가 자동으로 생성되었는지** 링크 리스트 목록을 통해 **확인한다**.
* 사용자는 **기존에 등록한 링크의 제목이나 URL 주소 오타를 고치기 위해** 해당 링크 블록 옆의 '연필 아이콘'을 누르고 입력창 모드에서 텍스트를 고친 후 화면 빈 곳을 마우스로 **클릭(Blur 처리)하여 즉시 저장한다**.
* 사용자는 **만료된 이벤트 페이지 등 더 이상 유효하지 않은 특정 링크를 리스트에서 완전히 빼기 위해** 해당 링크 블록 우측 끝의 '휴지통' 아이콘을 누른 뒤 나타나는 "정말 삭제하시겠습니까?" 컨펌창에서 '확인' 옵션을 **클릭한다**.

### 2-4. 통계 확인 및 URL 공유
* 사용자는 **자신이 올린 여러 링크들 중 방문자들에게 가장 반응이 좋은(가장 많이 눌린) 링크가 무엇인지 파악하기 위해** 대시보드 화면에 표시된 '각 링크 블록별 누적 클릭 조회수' 통계를 **조회한다**.
* 사용자는 **완성된 본인의 멀티 링크 채널을 널리 홍보하기 위해** 발급된 고유 프로필 URL을 '복사'하여 인스타그램 등 여러 외부 플랫폼 프로필 소개란에 **붙여넣는다**.
